## Added

* Added interface translations for 67 Minecraft locales.
* On Minecraft 26.1.2 and 26.2, added waypoint editor shortcuts for:
  * Tiny and filled subwaypoints
  * Hide after parent reached
  * Stand, interact, and mine triggers
  * Line-of-sight rendering
* On Minecraft 26.1.2 and 26.2, added automatic, configurable colors for dungeon waypoint actions.
* Added dungeon route controls for visible secret stages, route lines, tracers, Ender Pearl trajectories, and secret-completion sounds.
* On Minecraft 26.1.2 and 26.2, added an option to start route connector lines from Etherwarp height.

## Changed

* Redesigned the export page with clearer format selection, content controls, zone controls, and previews.
* Improved settings search and keyboard focus.
* Improved waypoint and group editing, including clearer movement feedback and easier flag review.
* Private-world routes can now move to another zone.
* Imported and downloaded dungeon secrets now use normal editable routes.
* Moved or edited dungeon routes now update without a reconnect.
* Improved waypoints, tracers, labels, beacons, and route lines near the player.
* Improved rendering when Iris shaders are active.
* Improved compact route and settings codes.
* Improved sharing with Chinese, Japanese, and Korean text.
* Invalid or damaged share codes now show safer errors.
* Updated SkyHanni route exports to use the current format.
* Contributor badges now appear in chat, the player list, and player name tags.

## Fixed

* Fixed covered or moved routes not loading after an edit.
* Fixed several dungeon route progression problems.
* Fixed chest interaction and room detection in dungeons.
* Fixed custom dungeon room-data problems.
* On Minecraft 26.1.2 and 26.2, hardened waypoint paint image imports and fixed texture cleanup after a failed texture build.
* Fixed route and settings values being lost during import, export, or restart.
* On Minecraft 26.1.2 and 26.2, invalid Waypointer configuration files are moved aside before default settings are saved.
* Improved performance-test reliability and recovery after an interrupted test.

## Removed

* Removed the `/wp devmode` command and its help entry.

## Compatibility

* Supports Minecraft 26.1.2 and 26.2; these builds require Java 25.
* A separate Minecraft 1.21.11 build is available and requires Java 21.
* This release supersedes the earlier plan for 1.8.5 to be the final Minecraft 1.21.11 release.
