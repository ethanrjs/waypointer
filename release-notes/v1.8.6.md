## Added

* Added support for 67 languages.
* More languages will come later.
* Added editor keybinds for these waypoint options:

  * Tiny
  * Filled
  * Hide
  * Stand
  * Interact
  * Mine
  * Line of sight
* Added automatic colors for dungeon waypoint actions.
* You can change these colors in the settings.
* Added an option to aim route lines at Etherwarp height.
* This option works for route connections and dungeon entrances.

## Changed

* Redesigned the export page.
* Export formats are now easier to select and preview.
* Zone-based exports are now easier to manage.
* Improved waypoint and group editing.
* Route movement now gives clearer feedback.
* Waypoint flags are easier to review.
* Private-world routes are easier to organize.
* Dungeon secrets now use normal editable routes.
* Moved or edited dungeon routes now stay updated without a reconnect.
* Improved waypoints, tracers, labels, beacons, and route lines near the player.
* Improved rendering when Iris shaders are active.
* Improved compact route and settings codes.
* Sharing now works better with Chinese, Japanese, and Korean text.
* Invalid or damaged share codes now show safer errors.
* Updated SkyHanni route exports to use the current format.

## Fixed

* Fixed covered or moved routes not loading after an edit.
* Fixed several dungeon route progression problems.
* Fixed chest interaction and room detection in dungeons.
* Fixed some custom dungeon room-data problems.
* Fixed waypoint paint image imports.
* Fixed some texture cache cleanup problems.
* Fixed route and settings values being lost during import or export.
* Fixed route and settings values being read incorrectly after a restart.
* Improved the performance stress test +6 system.
* Invalid configuration files are now kept instead of replaced with default settings.
* Fixed contributor badges in chat.
* Fixed contributor badges in the player list.
* Fixed contributor badges above player names.

## Removed

* Removed the `/wp devmode` command.
* Removed its help page entry.

## Compatibility

* Supports Minecraft 26.1.2 and 26.2 on the main maintained version.
* A separate Minecraft 1.21.11 version is available.
* The Minecraft 1.21.11 version requires Java 21.
