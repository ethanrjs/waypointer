## Added

* Added an optional 3D route preview to the export page. It is off by default; turn it on under Settings -> Sharing -> Export screen.
  * Rotating isometric view of the route you are about to share.
  * Arrows step through each selected route without changing what gets exported.
  * Scroll to zoom, with a reset control in the corner.
  * On wide windows the preview sits beside the export options; on narrow ones a Preview/Options switch shares the space.
* `/wp import` now accepts route codes, settings codes, and dungeon route codes through the one command.
* Share codes pasted inside Discord code fences now import without cleaning them up first.
* Added `/wp export config` and `/wp export dungeon`.

## Changed

* Dungeon route share codes are considerably smaller. Codes from earlier versions still import.
* `/wp import` now installs dungeon room routes as editable routes, matching `/wpd import`, the route downloader, and the in-game importer.
* Importing a single-route code now keeps the code's label as the route name.
* `/wp help` pages are separated by blank lines so back-to-back pages stay readable.
* Export chat feedback only offers the manual Copy link when the automatic clipboard copy did not work.
* Reworded the export length warning.

## Removed

* Removed Ender Pearl trajectories and their setting.
* Removed the seven waypoint editor shortcuts added in 1.8.6 (tiny and filled subwaypoints, hide after parent, stand/interact/mine triggers, line-of-sight rendering) along with the "Waypoint editor keybinds" settings entry. Waypointer now registers ten keybinds instead of seventeen, and no longer claims T, F, H, S, I, M, or R by default.
* Removed the in-game dungeon route recorder: `/wpd test`, `/wpd reset`, `/wpd room create`, `/wpd room rename`, `/wpd room fingerprint add`, and the `/wpd waypoint` subcommands. Dungeon routes are still fully editable once installed -- import or download them, then edit them like any other route. `/wpd info`, `room list`, `import`, `routes`, `route`, `rotate`, and `toggle` are unchanged.

## Compatibility

* Supports Minecraft 26.1.2 and 26.2; these builds require Java 25.
* There is no Minecraft 1.21.11 build for this release. 1.8.6 remains the last version published for 1.21.11.
