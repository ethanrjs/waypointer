# Waypointer 1.12.0
## Added
- Give a zone, a route or a single waypoint its own look. Open **Appearance...** from the route editor, the waypoint menu or the route menu. To set a look for a zone, use **Editing: Everywhere** in Settings > Appearance. Changes show live in the world. Rows you changed are marked, and the dot next to a row puts it back to the inherited value.
- **Peek** in the route editor hides the waypoint list so you can watch your coordinate edits in the world.
- **Add subwaypoint here** in the waypoint menu adds a new subwaypoint where you stand.
- **Reset to route color** in the waypoint menu puts a recolored waypoint back on the route's exact gradient color.
- `/wp route target` shows, pins or clears the route that new waypoints are added to.

## Changed
- New waypoints go to the route you are using: the one you last edited in that area, or the one drawn in a dungeon room. They no longer go to whichever route is listed first.
- Subwaypoints now fade in and out like main waypoints. "Skip fade time" is now called "Waypoint fade time".
- Load modes are called **Show all** and **Step by step** everywhere.
- "Make subwaypoint" is now **Turn into subwaypoint**. It is greyed out, with the reason, when it can't be used.
- Waypoint numbers in the route editor line up, and coordinates start in the same column on every row.
- Routes and waypoints with their own look are marked in the route list and the route editor.
- Shorter route catalog help text.

## Fixed
- Waypoints added in a dungeon room no longer go to a hidden route, and add-where-looking works in rooms.
- Edit mode projects the selected saved route inside dungeon rooms. Selecting waypoints in completed rooms remains unsupported.
- Recoloring one waypoint no longer resets the rest of a gradient route.
