# Waypointer 1.12.0
## Added
- New UI refresh, including main UI, community routes, your routes, settings, appearances, everything!
- You can now modify all appearance settings on a cascading appearance section (Global > Zone > Route > [Room] > Waypoint), you can change appearance settings for an individual waypoint or all of your routes.
- You can classify dungeon actions as *Do in any order* from the waypoint menu. Mostly for dungeonbreaker blocks.
- Room completions can now be timed
- Dungeon routes now work in 'steps', where the step you're on shows its actions and its secret together, rather than just going from waypoint to waypoint.
- Doing a later action in a step skips ahead to it, and a secret you grab early is skipped when the route gets there. (no more getting stuck on a missed etherwarp lol)
- You can now import SecretRoutes f7 boss routes
- You can now give routes icons (right click -> Icon)
- *Peek* in the route editor hides the waypoint list so you can watch your coordinate edits in the world.
- Menu opacity in Settings > System lets you see the world behind the menus while editing
- *Add subwaypoint here* in the waypoint menu adds a new subwaypoint where you're standing
- *Reset to route color* puts a colored waypoint back on the route's gradient color for that spot.
- `/wp target` shows/pins the route that new waypoints and commands go to.
- Added more commands for almost everything in the menus: routes, waypoints, folders, appearance, publishing and more. See `/wp help`.
- Support for Odin's new Waypoints module.
- Routes uploaded to the mining cult discord (will) automatically go to Waypointer's route catalog with a new pretty purple tag! :D

## Changed
- New, better algorithm to recommend routes in the route browser.
- Master Mode / Normal Mode function the same in dungeon rooms for the most part now.
- Edit mode in a dungeon room shows the whole route including finished rooms
- New waypoints go to the route you are using: the one you last edited in that area, or the one drawn in a dungeon room. They no longer go to whichever route is listed first (weird that it did that in the first place, sorry command-first users! didn't know so many people would use them ngl...)
- Subwaypoints now fade in and out like main waypoints. "Skip fade time" is now called "Waypoint fade time".
- Less explanatory text in menus and settings.
- Translations updated for every language that had them.
- Improved debug output

## Fixed
- Waypoints added in a dungeon room no longer go to a hidden route.
- Add where looking now works in dungeon rooms.
- Blocks mined out of order no longer hold up dungeon routes.
- `/wp` suggestions work on Hypixel again. (i think ive finally fixed it!)
- A known Crystal Hollows structure no longer turns into an 'approximate' waypoint when you walk into its area.
- Recoloring one waypoint no longer resets the rest of a gradient route.
- Unbound keybinds no longer show as conflicting with each other.
- Minimap area names move aside instead of disappearing behind markers.
- Shared route names can no longer use color codes or hidden characters to look like something else.

## Performance
- Long routes render much faster in the Crystal Hollows.
- Faster minimap, community route maps and route list.
