## Added
- 26.3 support
- In world labels (draws waypoints like nametags)
- /wp import relative (works like /cw ordered load)
- Better dungeon route pack management
- Export options readded (initially removed to simplify but was needed)
- Painter: brush and fill tools
- Route line opacity setting
- Route and waypoint IDs like @mod1 and @mod1#5 work in commands from anywhere; @1 means the area you're in. Tab completion suggests IDs, area prefixes, and finds IDs by route or area name
- Fairy Grotto routes (@fg1, @fg2, ...): a route remembers its grotto and is placed on it in any lobby
- Copy look / Paste look: copy appearance settings between Global, zone, route and waypoint (right-click menus too)
- In-world tracers setting, so tracers stay smooth with HUD caching (Lunar Client)
- /wp debug shows route IDs, a saved route list and recent import failures
- Optionally, you can export codes without angle brackets for pasting in Youtube descriptions, but they will only be supported by Waypointer 1.14+

## Changed
- Routes’ reach radius changes with your global reach radius unless you change it manually
- Community browser is now like a billion times faster idk i don’t feel like doing a benchmark but it’s insanely fast
- Faster rendering
- Removed a bunch of useless tooltips they cluttered the screen
- Updated i18n
- The menu opens on the island you are on; an island picked in the menu stays until you leave the area (#198)
- Error messages are shorter and more formal

## Fixed
- Crystal follows approximation is incorrect
- Default reach radius not propagating with changes
- Edge cases for import codes
- A damaged import code now says it's damaged instead of printing every decoder's error
- Deleting a route by ID asks to confirm with a command that names that route
- Performance issues fixed
