## Added
- Minecraft 26.3 support, alongside 26.1.2 and 26.2
- In-world labels: waypoint labels drawn in the world like nametags, hidden by blocks
- Dungeon route packs screen to use, hide or delete imported packs
- Export options button for what a code includes
- Waypoint Painter brush and fill tools, and removing paint
- Route line opacity setting
- Codes without < or > for sites that strip them (Waypointer 1.13 and older can't import these)

## Changed
- Routes follow the default reach radius when you change it, unless you set theirs by hand
- Community browser opens instantly and keeps its list and maps for the session
- Faster rendering with big or busy routes: progress labels, beams, tracers, route lines and route updates
- Most tooltips removed; the rest only say what isn't on screen
- Community routes that need a newer version now say to update Waypointer
- Translations updated

## Fixed
- Crystal Hollows approximate markers overriding better structure locations
- Default reach radius not reaching imported and older routes
- ColeWeight and SkyHanni lists in a Skyblocker header not importing
