Waypointer 1.10.0 adds V10 sharing for routes, settings, and dungeon routes, plus ChunkLogger RouteSkipper compatibility.

## Highlights

* Every Waypointer code is now a `WP:` code. V10 shares cover routes, route libraries (folders, manual colors, paints), configuration, and dungeon routes, so you never have to know which kind of code you were handed. Coordinate-only exports are compact by default, and every older code (`WP:` V1-V9, `WPL:`, `WPC:`, `WPD:`) still imports.
* Added ChunkLogger RouteSkipper import and export. Main waypoints become route points and subwaypoints become `coal` block shapes; fields the format cannot represent are omitted rather than invented.
* Chat share detection now identifies route, configuration, and dungeon shares separately. Clickable pills import the right type, invalid shares are marked clearly, and configuration imports require confirmation before changing settings.
* Pasting a configuration code into the route screen's import button now opens the same review prompt as Settings instead of refusing it.
* Added `/wp export bare` for coordinate-only route exports.

## Improved

* Per-route painted waypoints now render without requiring the global Paint box style, and export previews keep painted surfaces' depth behavior consistent with the world renderer.
* Etherwarp alignment cues now offer Off, Experience, Pling, and Bell sounds.
* Contributor badges now recognize acidangels in chat, player names, and the player list.
* Route publishing enforces its 500-character description limit by Unicode code points, including non-ASCII text.

## Compatibility

* Supports Minecraft 26.1.2 and 26.2; both builds require Java 25.
* New V10 exports require Waypointer 1.10.0 or another V10-compatible importer. Waypointer 1.10.0 still imports existing V1-V9 route codes, `WPL:` library codes, `WPC:` configuration codes, and `WPD:` dungeon codes.
