## Added
- Update button in Settings, installs on restart
- Odin export for island waypoints and dungeon room packs
- Export option in the route right-click menu
- Label color setting, optionally applied to all label text
- Hex colors in waypoint names (`&#ff8800` or `<#ff8800>`)
- Live color preview for color codes and placeholders in the name editor
- Number unnamed waypoints setting
- Peek in Appearance settings
- Usage hints for incomplete commands

## Changed
- New share code format v11 with more compatibility for customization
- Export screen simplified to format and copy; export options moved to `Settings > Sharing > Exports` and on by default
- Dungeon rooms use the regular export screen
- Community routes that need a newer version now say which one
- Route publishing now defaults to Public
- Crystal Hollows structure waypoints now hidden by default on new installs
- Single-route dungeon rooms show as one row to save precious vertical space
- Cursor changes over clickable elements and text fields now

## Removed
- 3D route preview and the Extras settings page (did anyone use ts)

## Fixed
- Dungeon item secrets completing when walking past instead of on pickup
- Bat secrets not counting when killed through walls
- Missing dungeon step labels (e.g. Item)
- Pathfinding not working in dungeon step routes
- Walking path drawing through walls and in the wrong color
- Pathfind to all waypoints doing nothing unless Pathfind to first waypoint was on
- Tracers missing for dungeon steps with Show tracers on
- Odin dungeon waypoints importing offset and without their colors
- Open link after importing a room not jumping to that room
- Crystal Hollows structure route looks not saving
- Contributor badge hiding the emblem in the tab list (thanks akura)
