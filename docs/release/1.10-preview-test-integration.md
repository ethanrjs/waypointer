Independent Astra review also checked 5,805,100 samples over 360 yaw positions with no interior mismatches.

## Route paint precedence

The release candidate already contains the earlier fix that makes per-route paint participate in retained geometry visibility and invalidation even when global box style is outline-only. This pass strengthens that regression across every global box style: painted routes remain eligible, reserve their texture, and suppress ordinary RGB fill. A route-paint edit or enablement change also changes the retained scene key.

The separate **Color waypoints by sequence role** setting intentionally replaces painted sequential routes with role-colored RGB. Its existing behavior and regression tests remain. Global opacity settings also remain effective. These automated checks prove renderer decisions and invalidation; actual GPU appearance has not been verified in a live game during this pass.
