# Waypointer 1.10 codec size investigation

Base: `8e85aea` (`release/1.10-rc`). Work is isolated on `perf/codec-route-benchmark`.

## Scope and acceptance

Use actual complete share strings, including prefix, checksum, escaping, and text encoding. Compare both characters and UTF-8 bytes. Coordinate-only comparisons must retain the same ordered integer coordinates; richer comparisons must explicitly identify retained fields. Do not make universal superiority claims from a finite corpus or compare stripped Waypointer codes with rich competitor payloads without disclosure.

The supplied JSON contains 302 routes and 31,418 points, matching the counts of the existing V10 locked corpus. It is not evidence of an unseen evaluation set. SHA-256: `2179ccf560c24291fa706cdbf8b89c2d36fc526560040bfa717a30675a3d21d7`. Keep the raw attachment outside source control. Hash identical coordinate sequences into the same deterministic evaluation group. Report actual short routes separately from synthetic prefixes.

## Work plan

1. Astra benchmark agent: strict source validation, reproducible JSON/CSV reports, existing production peer writers, round-trip assertions, comparable feature projections, short-route strata.
2. Astra compression agent: inspect predictors and entropy choices, measure candidate sizes, identify compatible encoder-only opportunities before introducing wire changes.
3. Astra envelope agent: quantify tiny-route overhead and compatible transport opportunities. Include CPU cost and compatibility in recommendations.
4. Integrate only measured improvements, independently review correctness and malformed-input behavior, and retain all historical decoding support.
5. Run regression tests and repeat the same benchmark on the changed implementation. Record exact evidence and limitations, including any losing cases and rejected experiments.

The independent general polish task owns broader 1.10 UX and renderer fixes. Coordinate heavy Gradle runs across tasks; use Java 25 and at most two Gradle workers.

## Completed outcome

The benchmark identified a substantial existing-format opportunity after the coordinate/envelope experiments proved too small: equivalent names/colors/zone exports now consider the existing compact full body under exact default-value checks. Production commit `de8b0ea` reduces that projection by 47.36% across the corpus with no enlarged routes or decoder change. The original decoder accepted the newly selected compact shares in independent review.

The optimized 13,417-row benchmark, independent arithmetic review, focused tests, and both supported target builds passed. Full results, losing cases, and reproduction commands are in [the size report](1.10-codec-size-results.md); compatibility and adversarial findings are in [the independent review](1.10-codec-adversarial-review.md).
