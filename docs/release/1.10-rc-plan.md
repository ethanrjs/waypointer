# Waypointer 1.10 release candidate plan

Updated 2026-09-04. Goal: combine the V10 codec and retained renderer with completed Crystal Hollows work and reviewed issue fixes. Priorities: reliable, fast import/export; renderer correctness and measured performance; remaining GitHub issues; release evidence.

## Source state

- `origin/main`: `2fa0169` (1.9.2).
- `origin/feat/codec-v10`: `68ba1fa`.
- `origin/feat/new-renderer`: `acb584c`.
- `feature/mining-foraging`: `06db9b1`, includes Crystal Hollows `44f8714` and initial fixes for #124, #125, #126, #130.
- `origin/beta` is already an ancestor of the combined feature branch.
- Candidate: `release/1.10-rc` in a separate worktree. Main, beta, and previous worktrees are preserved.

## Plan and acceptance gates

1. Resolve renderer merge preserving independent route paint and retained-texture fallback. Inspect automatic merges in client lifecycle and config codecs.
2. Three Sol xhigh reviews: import/export and publication; renderer lifecycle/performance; issues and feature integration. Review concrete findings before implementation. Coordinate all builds serially.
3. Fix reproducible data-loss, correctness, latency, and lifecycle defects with focused behavior tests. Preserve backward import compatibility and existing publisher credentials.
4. Complete missing issue behavior and the settings organization already planned by Fable. Treat speculative new mining/foraging packages as follow-up scope unless required by an open issue; do not rush unverified gameplay features into this candidate.
5. Run the complete build/check suite for Minecraft 26.1.2 and 26.2, with existing coverage and documentation gates. Verify 26.1 compatibility separately from widening metadata.
6. Record reproducible codec and renderer CPU measurements, scenario sizes, limitations, and comparison methodology. In-game GPU/FPS, shader compatibility, and Hypixel interaction claims require live evidence.
7. Produce an issue-by-issue disposition and release notes. Commit reviewed changes to the candidate branch. Do not publish a release, close issues, or merge the candidate into main/beta without release authorization.

  compact folder creation, per-route paint invalidation/overflow, retained-origin
  stability, and core-based SecretRoutes mapping.

  stalled session B process was interrupted after its clean committed state was
  recovered. No new mining/foraging gameplay packages were rushed into the RC.

  results and their limits are in `1.10-rc-verification.md`.
- Final local two-target build passed with 1,758 tests, zero failures/errors.
  The verification document records coverage and measurement results. The pushed
  release branch also runs CI with its source-pinned remote locale manifest.

## Release decision

This branch is a reviewable release candidate. Publication still requires the
live-client/Hypixel/renderer matrix in the verification document. Open GitHub
issues have code-level dispositions in `1.10-rc-issues.md`; they were not closed
based only on unit tests.
