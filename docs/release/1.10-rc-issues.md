Additional review fixes:

- Export previews coalesce rapid changes and run separately from explicit import
  operations. Stale or failed preview results cannot leave the newest export stuck.
- SecretRoutes room imports resolve pinned source core hashes against the bundled
  Odin catalog. This corrects five wrong aliases and other unmatched room names;
  Odin packs retain their original name-matching behavior. Boss route `f7boss`
  has no corresponding room identity and remains explicitly unmatched. Retired
  `Four-Banner-1` and ambiguous suffix-free `Waterfall` are also left unmatched;
  verified suffix-free source names remain supported.
- Crystal Hollows settings are grouped under Mining. No empty Foraging tab or
  speculative new gameplay subsystem was added to this candidate.
- CI checks release branches and enforces the documentation gate. Serial target
  builds inherit the caller's worker limit.
