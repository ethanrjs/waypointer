# Waypointer 1.10 route-size benchmark

Measured 2026-09-04. Baseline: `8e85aea`. Production improvement: `de8b0eafdd36fc94fd83a324f5b2404104229210`. Four Astra xhigh agents contributed the benchmark, compression experiments, envelope audit, and independent adversarial review.

## Implemented improvement

Exports retaining **names, colors, and island**, with waypoint flags, radii, and group metadata disabled, previously excluded the existing compact full body even when the omitted values already matched their defaults. The encoder now considers that body under strict equivalence checks and selects it only when its complete transport wins. No wire grammar, checksum, canonical decoder, coordinate-only policy, or catalog format changed.

| Equivalent shared-feature projection | Routes | Before | After | Reduction |
|---|---:|---:|---:|---:|
| Skyblocker common fields | 302 | 177,664 | 93,529 | **47.36%** |
| Skytils V1 common fields, supported islands | 50 | 10,126 | 9,064 | **10.49%** |

All sizes are complete UTF-8 bytes; these native codes are ASCII, so character counts are identical. The first projection improved 266 routes, left 36 unchanged, and enlarged none. The second improved 27 and left 23 unchanged. Coordinate-only and native full-detail outputs are unchanged across all 302 routes.

Eligibility is deliberately narrow: a single regular route with manual colors, sequence loading, default group radius/palette/skip-ahead, no custom point radii, 24-bit point colors, and no flags or precision the requested projection would discard. Required persistent flags and precise subwaypoint positions remain intact. All other inputs keep the existing selection path. This avoids projecting away user data merely to win a benchmark.

The candidate experiment used four warmups and seven alternating corpus passes: median general-only encoding was 275.6 ms versus 296.2 ms with compact selection, approximately 7.5% more for the corpus. These are exploratory local JVM measurements, subject to JIT and scheduling effects; they are not a gameplay latency guarantee.

## Peer comparisons

Coordinate-only Waypointer shares preserve the same ordered block coordinates. Peer formats may mandate extra fields; those costs are included and disclosed. These are the production export formats implemented by this repository, not a claim covering every codec/version in existence.

| Format | Matched routes | Waypointer bytes | Peer bytes | Waypointer reduction |
|---|---:|---:|---:|---:|
| Skyblocker V1, gzip/Base64 | 302 | 75,674 | 332,798 | 77.26% |
| Skytils V1, gzip/Base64 | 50 | 3,716 | 22,380 | 83.40% |
| SkyHanni/Coleweight-style production raw JSON | 302 | 75,674 | 2,325,366 | 96.75% |
| ChunkLogger production JSON | 302 | 75,674 | 1,106,671 | 93.16% |

Waypointer wins every matched row above. Skytils cannot encode 252 source islands in the supported recipient schema; those rows are explicitly unsupported, not wins. Its mandatory live timestamps make exact sizes slightly variable; the benchmark uses the smallest of three unmodified exports, favoring the peer. Skytils V2 Brotli is not measured as a named peer. SkyHanni is explicitly the raw JSON export, not its smallest conceivable compressed representation.

With names, colors, and island retained on both sides, optimized Waypointer is **78.81% smaller** than Skyblocker (93,529 versus 441,366 bytes, all 302 routes) and **67.41% smaller** than Skytils V1 (9,064 versus 27,808 bytes, 50 supported routes). Peer name sanitization is applied identically on both sides and each changed-name count is recorded; native full-detail comparisons retain source names.

## Stronger generic controls

These independent Node.js controls use arrays of coordinate triples rather than verbose waypoint objects. Delta variants reconstruct the original coordinate order exactly. They receive no added version, share prefix, count, or checksum beyond their compression format; Base64 is included. They are not advertised as named mod formats.

| Generic control, all 302 routes | Bytes | Waypointer coordinate reduction |
|---|---:|---:|
| Gzip level 9 coordinate JSON / Base64 | 207,488 | 63.53% |
| Brotli quality 11 coordinate JSON / Base64 | 156,332 | 51.59% |
| Brotli quality 11 delta JSON / Base64 | 136,860 | 44.71% |
| Brotli quality 11 signed int32 delta bytes / Base64 | 126,516 | **40.19%** |

Every compression and coordinate reconstruction round trip is asserted. Waypointer's 75,674 bytes beat every control on every route.

## Limits and losing cases

**V10 does not universally beat V9.** Coordinate-only totals are 75,674 versus 79,426 bytes (4.72% smaller), with 289 wins and 13 losses. Native full fidelity is **1.28% larger**: 93,723 versus 92,539 bytes, with 104 wins, 4 ties, and 194 losses. This change does not fix that separate full-fidelity overhead tradeoff.

The attachment contains 302 routes / 31,418 points / 298 unique ordered coordinate sequences, with SHA-256 `2179ccf560c24291fa706cdbf8b89c2d36fc526560040bfa717a30675a3d21d7`. Its counts match the pre-existing locked corpus, so retrospective hash partitions do not establish independence from prior tuning. Four duplicate geometries remain together in the split. Source-weighted totals are primary; deduplicated peer totals retain the first source representative, whose mandatory metadata or island support can differ from another copy.

The strict adapter rejects fractional coordinates, unknown fields, duplicate JSON keys, malformed UTF-8, and unsupported source shapes. Normalized RGB floats are explicitly rounded to 8-bit channels; integer point names are explicitly stringified; island aliases use the existing importer map. Full fidelity refers to that native model, not raw decimal RGB or source URL/type provenance.

Actual routes have 3–5,000 points. The 16 real 3–5-point routes have median 24-character coordinate shares. There are **no real 1–2-point routes**. Deduplicated synthetic prefixes have median lengths 15/19/22/27/39 characters at 1/2/3/5/10 points; those samples are correlated slices, not additional independent routes.

## Rejected experiments and review

Twenty-seven DEFLATE level/strategy combinations saved only 5 bare-route characters in total. New predictor/block/diagonal bodies saved only 45; a hypothetical tiny count-in-header format saved 84. A normalized general candidate saved 62 bare-route characters with additional search work; sparse quotient gains were at most 82 characters on synthetic metadata routes. These changes did not justify their CPU or compatibility costs. Their reproducible harnesses and limitations are in [the experiment notes](../../tools/codec-experiments/README.md) and [the envelope review](1.10-codec-envelope-review.md).

Astra independently checked all 13,417 comparison rows and 564 summaries. For the production patch, a separate 80-case adversarial matrix checked complete waypoint records, group settings, source immutability, exact general-projection equivalence, and no size regression. The original `8e85aea` compact decoder accepted all 25 newly selected compact shares in that matrix. Existing no-names canonical selection and historical golden input strings were retained.

## Reproduce

Use Java 25 and keep the raw attachment outside the repository:

```sh
./gradlew test --tests '*CodecRouteBenchmarkTest' --tests '*CodecRouteCorpusTest' \
  -Pcodec.routes=/path/to/waypoints.json -Pcodec.report=/path/to/report.json --max-workers=2
node tools/codec-compression-controls.mjs /path/to/waypoints.json /path/to/controls.json
./gradlew writeCodecExperimentClasspath --max-workers=2
python3 tools/codec-experiments/run_existing.py /path/to/waypoints.json \
  --common-compact --classpath-file build/reports/codec-experiment-classpath.txt \
  --java-home /path/to/jdk-25
```

The main benchmark emits JSON methodology, integrity checks, per-route records, summaries, and a sibling CSV. The source corpus and generated share codes are not committed. A compact metrics snapshot accompanies this report in `benchmarks/1.10-codec-size-summary.json`.

## Validation

The focused codec suite plus the complete optimized corpus report passed in 13 seconds. Both Minecraft 26.1.2 and 26.2 release builds then passed through `buildAllTargets` in 40 seconds, including tests, coverage thresholds, documentation-version checks, and access-widener validation. The final target reported 1,766 tests, zero failures/errors, and 10 expected skips; the opt-in corpus benchmark was run separately with its attachment supplied. The build used translation commit `de8b0eafdd36fc94fd83a324f5b2404104229210`.

This is codec correctness/build evidence. Interactive Minecraft, GPU, Iris, and Hypixel runtime checks remain part of the separate general release pass. No public release was published by this benchmark work.
